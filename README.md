# PakSimInfo - SIM Owner & CNIC Verification Portal

Pakistan's most trusted platform for verifying mobile number ownership and CNIC information. Fast, accurate, and confidential.

## 📁 Project Structure

```
/workspace/
├── index.html              # Main landing page with SIM & CNIC verification
├── privacy-policy.html     # Privacy policy page
├── terms-of-service.html   # Terms of service page
├── blog.html               # Blog section with articles
├── css/
│   └── style.css           # Main stylesheet (1300+ lines)
├── js/
│   └── main.js             # JavaScript functionality
└── README.md               # This file
```

## ✨ Features

### Main Page (index.html)
- **SIM Owner Verification** - Check mobile number owner details
- **CNIC Verification** - Verify National Identity Card information
- **Dark/Light Mode Toggle** - User preference theme switching
- **Responsive Design** - Mobile-first, works on all devices
- **Real-time Captcha** - Security feature for form submissions
- **Stats Counter Animation** - Live statistics display
- **FAQ Accordion** - Common questions section
- **Contact Form** - User support integration
- **Print-friendly Reports** - Generate printable verification reports
